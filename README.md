# Cryptography Assignments 🔐

This repository documents my coursework and hands-on exercises in cryptography.

The assignments cover different cryptographic concepts, including classical ciphers, symmetric key encryption, asymmetric key encryption, and digital signatures.

## Assignments Overview

### Assignment 1: Classical Ciphers & DES

Topics covered:

#### Classical Cryptography

- Transposition Cipher
- Caesar Cipher
- Simple Substitution Cipher
- Playfair Cipher Matrix

#### DES (Data Encryption Standard)

Solved exercises related to DES components:

- Initial Permutation (IP)
- S-Box
- Expansion Permutation
- Subkey Generation for the 4th Round

### Assignment 2: AES (Advanced Encryption Standard)

Topics covered:

- AddRoundKey
- SubBytes
- MixColumns
- AES Key Expansion (Key Schedule)

### Assignment 3: Public Key Cryptography

Topics covered:

#### RSA Cryptosystem

- RSA Encryption and Decryption
- Key Generation

#### Diffie-Hellman Key Exchange

- Shared Secret Key Generation
- Key Exchange Process

### Assignment 5: Asymmetric Encryption & Digital Signature

Topics covered:

- Asymmetric Key Encryption
- Digital Signatures
- Public and Private Keys
- Signature Verification

## Tools & Concepts

- Cryptographic Algorithms
- Symmetric Key Encryption
- Asymmetric Key Encryption
- Public Key Infrastructure (PKI)
- Digital Signatures

This repository documents my coursework and learning progress in cryptography, including both theoretical exercises and hands-on activities.
